### How to Install and Get Started with Your Website

Follow these steps to deploy and configure the CMS on your web server:

* **Step 1: Download the CMS Package**
  Download the latest ZIP archive of the Script CMS from the official source to your local device.

* **Step 2: Prepare the Server Root Directory**
  Log in to your hosting account via an **FTP client** (or your hosting control panel's File Manager). Ensure that the target root directory (usually `public_html` or `www`) is completely empty. Remove any default placeholder files if necessary.

* **Step 3: Upload and Extract the ZIP File**
  Upload the downloaded ZIP archive to your root directory. Once uploaded, use your hosting **File Manager** (e.g., cPanel or Plesk) to extract the archive. 
  *(Note: Standard FTP clients do not support remote file extraction. If you only have FTP access, extract the ZIP locally on your computer first, then upload all unzipped files and folders).*

* **Step 4: Launch the Web Installer**
  Open your web browser and navigate to your domain followed by `/install` (for example: `://example.com/install`). This will initialize the setup wizard.

* **Step 5: Create your Administrator Account**
  Follow the on-screen instructions to set up your master admin profile by entering your name and a secure password.

* **Create your own website!**
