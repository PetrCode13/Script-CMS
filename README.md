# ScriptCMS ™

What is CMS?
CMS is website system for create, edit and manage your websites easy and clearly.

## What to expect?

#### Fast, Easy, reliable and powerful.
ScriptCMS is a CMS inspired by Grav CMS. It differs in several things that users will appreciate, such as:
-Easy to install
- Easy management 
- You don't need to know any programming language. 
- Runnable on any web hosting and on any domain.
- Visitors to your website can expect fast loading times, easy navigation, and a great look.

### `Technical specifications`
`Written 100% in the modern PHP programming language`

`Everything is stored directly on your website, we do not collect any data`

`*No annoying* banners, cookies or ads for a better experience and smoother running. `

`128 times lighter than GravCMS and about 400 times lighter than Joomla or WordPress`

`Very suitable for beginners`

## How to install on my website?

#### Easy installation, the first step to successful websites.

ScriptCMS you install it easily:
- Step 1.: Download the system ZIP (see Releases) for manual extraction or a PHP script (also Releases) that will download and extract the ZIP itself (PHP is easier ;-)
- Step 2.: Login to your webhosting administration (where you purchased the domain.)
- Step 3.: Find and click on File Manager or FTP
- Step 4.: Find and click the Upload File button. You will be prompted to select the file(s). Select either the PHP script you downloaded or select ZIP if you want to extract system manually.
- Step 5.: (Note: If you download a PHP script, skip this step and jump to Step 6.) If you downloaded a ZIP, select it (most often left or right click on the square next to the name) and find the "Extract" or "Unzip" button and click it. If prompted to confirm it.
- Step 6.: (Note: If you download a ZIP file, skip to Step 7.) If you download PHP script, click to "Upload" and select downloaded PHP file.
- Step 7.: If you upload and extract (Unzip) a ZIP file or PHP file, go to: example.com/install. Here will be a installation guide.
- Step 8.: The wizard will guide you through the installation, which includes creating an administrator account to log in to the system. It is recommended to choose a password that contains: uppercase and lowercase letters, at least one number and at least 6 digits.
- Step 9.: After creating an account, the wizard will direct you to log in. Click "Log in" and enter the name and password you chose during installation and account creation. After click the "Login" or "Continue". After it will send Verify Code to your email address (which you also provided during installation). Enter it in the code field and click "Verify and Login".
- Step 10.: You have fully installed ScriptCMS and can start using it. Instructions etc. can be found below.

## Tutorials

#### Login
Go to example.com/admin and follow the instructions

#### Text editor
After logging in, click on "Content" and you will see a list of your pages. Select the page you want to edit or click on "New Page" to create a new page. After creating or selecting a page, a visual WYSIWIG editor (an editor very similar to Microsoft Word) opens where you can edit texts, add images, tables, headings, etc. For the full functionality of your websites, NEVER DELETE the index.md and 404.md files.

#### Users Manager
After logging in, click on "User Management", where you will see a list of users and the option to delete and create them (you need to choose their name, password, email and rights - the Editor is only allowed to edit texts and content and the administrator is allowed to edit texts, images, website content, Updating system and manage users.). 

#### Updating & Updater 
Updater you can find in button "Update". The system will automatically find available updates and, if any are available, will offer to update them. To update, click the "Update" button. The update never deletes data, so after The update will not destroy the websites or lose any data.
